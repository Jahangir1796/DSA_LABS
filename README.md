# DSA Labs

This repository contains the Python lab work for Data Structures and Algorithms
and related data-science exercises.

## Lab scripts

All lab scripts are kept in the repository root:

- `LAB01.py` through `LAB09.py`

## Supporting files

The CSV and JSON files in the repository root are supporting data and output
files used by the lab exercises.

## Running a lab

Run a script with Python from the repository root:

```powershell
python LAB01.py
```

Some labs may require packages such as NumPy, pandas, Matplotlib, seaborn, or
scikit-learn.
